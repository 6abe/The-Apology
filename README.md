# The-Apology

Hi-bit cyberpunk isometric action RPG (Vite + React + TypeScript + React Three Fiber + Three.js + GLSL).

Agreed art from Game Art Director / spryte lives under `public/assets/`.

## Run the scene

Keepers live under `public/assets/agreed/`. The demo draws `packs/player_walk_00_64.png`.

1. Install dependencies.

```
npm install
```

2. Start the dev server. Open http://localhost:5173.

```
npm run dev
```

3. Typecheck.

```
npm run typecheck
```

4. Build and preview the production bundle.

```
npm run build
npm run preview
```

If the keeper is missing or the wrong size, the same 64x64 quad draws an 8 px checker with one cyan cell and the console prints the reason.
